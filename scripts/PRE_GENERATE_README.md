# 预生成教程功能说明

## 功能概述

为了加速用户点击首页木块活动时的响应速度，我们实现了预生成教程功能。系统会为热门活动预先生成教程内容并**永久保存在数据库中**，这样用户点击时可以直接从数据库读取，无需等待AI API响应，大大节省API额度。

## 数据库迁移

在Supabase SQL Editor中执行以下SQL脚本来创建预生成教程表：

```sql
-- 文件位置：scripts/pre_generated_tutorials.sql
```

执行后会创建：
- `pre_generated_tutorials` 表：存储预生成的教程数据
- 索引：加速查询
- 触发器：自动更新 `updated_at` 字段

## 初始化预生成教程（推荐方式）

### 方式一：使用初始化脚本（推荐）

**一次性生成所有预生成教程，永久保存在数据库中：**

```bash
# 安装 tsx（如果还没有）
npm install -D tsx

# 运行初始化脚本
npx tsx scripts/init-pre-generated-tutorials.ts
```

脚本会：
- 检查每个活动是否已存在预生成数据
- 只对不存在的活动调用AI API生成
- 将结果永久保存到数据库
- 显示详细的统计信息

### 方式二：使用管理员API

```bash
# 调用管理员API（需要认证）
curl -X POST http://localhost:3000/api/admin/init-pre-generated \
  -H "Content-Type: application/json"
```

### 方式三：首页自动触发（备用）

如果脚本和API都不可用，首页组件会在首次加载时自动触发预生成：
- 使用 localStorage 标记，避免每次加载都调用
- API层面会检查是否已存在，不会重复生成
- **建议：优先使用脚本方式，避免消耗API额度**

## 工作流程

1. **初始化阶段**：运行初始化脚本，一次性为所有热门活动生成教程并保存到数据库
2. **用户点击木块**：创建教程API会先检查预生成表，如果存在则直接使用，否则调用AI API
3. **预生成列表**：当前预生成的活动包括：
   - 健身
   - 做饭、旅行
   - 蹦极、购物、开车
   - 画画、唱歌、读书、拼豆

## API端点

### POST `/api/tutorials/pre-generate`
预生成单个教程（如果已存在则跳过）

**请求体：**
```json
{
  "input_text": "健身"
}
```

### PUT `/api/tutorials/pre-generate`
批量预生成多个教程（如果已存在则跳过）

**请求体：**
```json
{
  "activities": ["健身", "做饭", "旅行"]
}
```

### POST `/api/admin/init-pre-generated`
管理员API：初始化所有预生成教程（推荐在部署时调用一次）

## 性能优化

- **永久保存**：预生成的教程永久保存在数据库中，不会重复生成
- **智能检查**：API层面会检查是否已存在，避免重复调用AI API
- **并发控制**：批量预生成时，每次处理3个活动，避免过载
- **localStorage缓存**：首页组件使用localStorage标记，避免重复触发

## 注意事项

1. **推荐在部署时运行一次初始化脚本**，确保所有预生成教程都已保存在数据库中
2. 预生成的教程数据存储在 `tutorial_data` JSONB字段中
3. 如果预生成失败或不存在，用户点击时仍会调用AI API生成（降级处理）
4. 数据永久保存，不会因为页面刷新而丢失
5. 初始化脚本只需要运行一次，之后所有用户都能享受快速响应
