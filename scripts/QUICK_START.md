# 快速开始：初始化预生成教程

## 为什么需要预生成？

预生成的教程会**永久保存在数据库中**，用户点击木块时直接从数据库读取，无需调用AI API，大大节省API额度并提升响应速度。

## 快速步骤

### 1. 执行数据库迁移

在 Supabase SQL Editor 中执行：
```sql
-- 文件：scripts/pre_generated_tutorials.sql
```

### 2. 运行初始化脚本

```bash
# 安装依赖（如果还没有）
npm install -D tsx

# 运行脚本
npx tsx scripts/init-pre-generated-tutorials.ts
```

脚本会：
- ✅ 检查每个活动是否已存在
- ✅ 只对不存在的活动调用AI API
- ✅ 将结果永久保存到数据库
- ✅ 显示详细的统计信息

### 3. 验证结果

脚本运行完成后，你会看到类似输出：
```

============================================================
```

### 4. 完成！

现在所有热门活动的教程都已保存在数据库中，用户点击时会立即响应，无需等待AI API。

## 注意事项

- ⚠️ 脚本只需要运行**一次**
- ✅ 数据永久保存，不会丢失
- ✅ 如果某个活动已存在，脚本会跳过，不会重复生成
- ✅ 即使脚本失败部分活动，也可以重新运行，不会重复生成已存在的

## 替代方案

如果脚本无法运行，可以使用管理员API：

```bash
curl -X POST http://localhost:3000/api/admin/init-pre-generated
```

或者让首页自动触发（首次访问时，但会消耗API额度，不推荐）。
