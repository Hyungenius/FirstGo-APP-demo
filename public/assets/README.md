# 资源文件说明

## 牛仔角色图片

要将您图片中的牛仔角色添加到应用中，请按以下步骤操作：

1. **准备图片文件**：
   - 将您的牛仔角色图片保存为像素艺术风格
   - 推荐格式：PNG（支持透明背景）
   - 推荐尺寸：64x64 像素或更大（保持像素艺术风格）
   - 文件名：`cowboy.png`

2. **放置文件**：
   - 将 `cowboy.png` 文件放到这个目录：`/public/assets/cowboy.png`
   - 确保文件路径正确

3. **图片要求**：
   - 像素艺术风格（避免使用抗锯齿）
   - 透明背景（PNG格式）
   - 尺寸建议：64x64 到 128x128 像素

4. **验证**：
   - 放置文件后，刷新浏览器页面
   - 如果图片加载成功，会显示您的牛仔角色
   - 如果图片不存在或加载失败，会自动显示 emoji 🤠 作为备用
